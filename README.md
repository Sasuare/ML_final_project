## 📘 Descripción
Proyecto realiado durante el estudio y capcitación de Polygon en el nivel 2 de inteligencia artificial.
El objetivo es obtener el conocimiento delos contenidos compuestos ysu puesta en práctica


---

## 🚀 Objetivos
- Construir un ejercicio de clasificación binaria que garantice un accuracy mayor al 90%
- Integrar herramientas que faciliten el Machine learning DevOps como DVC (Data Version Control para version de dataSet), MLFlow (Trazabilidad de experimentos) -  Gradio para construir interfaces grafizas - HuggingFace para alojar el proyecto y GitHub actions para simplificar y automatizar flujos de trabajo 

---
